## VyaparQuotes — GST Quotation Maker for Indian Entrepreneurs

A React Native / Expo mobile app that lets small businesses:

1. Set up their brand (logo, company info, GSTIN, bank & UPI details)
2. Maintain a product catalogue with HSN + GST rates
3. Build quotations quickly (pick products, set qty/discount)
4. Generate and share professional GST quotation PDFs (WhatsApp/email)
5. Track quotation status (draft → sent → accepted/rejected)

See [`quotation-app/README.md`](quotation-app/README.md) for full details.
